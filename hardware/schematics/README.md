# Proto-card schematic (Altium / HelloFPGA style)

## Open

**`red_proto_card_schematic.pdf`**

Drawn to match the look of the Smart Zynq SP's own schematic (from the
board maker's documentation): blue IC bodies, red net labels, pin numbers outside, title block, A4 landscape.

Connectivity is by **identical red net names** across sheets (Altium-style), not spaghetti wires.
